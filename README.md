# SkillSync 🚀

### Smart Team Matching Platform

SkillSync is a data-driven platform that helps students find the right teammates
for projects based on skills, interests, experience, and availability.

##  Live Demo

https://skill-sync-eight.vercel.app/

##  Features

-  Smart team matching
-  Skill-based compatibility
-  Interest alignment
-  Compatibility score breakdown
-  Talent pool
-  User profiles
-  Authentication
-  Real-time database integration
-  Responsive UI
-  Explainable matching results

##  How Matching Works

SkillSync evaluates candidates using:

- Skills
- Interests
- Experience
- Availability

These factors are combined to generate a compatibility score
and explain why a candidate is recommended.
